GET CONNECTED

Your classroom, in the browser.

  1. Run this gateway on your school network.

    It needs to reach each computer’s Veyon service port, usually 11100. Teachers connect to this website.

  2. Configure gateway authentication.

    On the gateway, run php scripts/setup.php for the teacher login. In config/local.php, set the Veyon private key path and key name, or Veyon logon credentials. Restart the server after changes.

  3. Add computers and connect.

    Enter each machine’s hostname/IP and classroom. Desktop pictures refresh automatically at your chosen interval. Open View for live video, or Remote control for keyboard and mouse input.

  4. Share securely with your teachers.

    Use Apache with PHP and HTTPS, proxy /remote to the PHP worker, and set origin in the PHP configuration. Keep access on your school network or VPN.

Veyon WebAPI is not needed for screen viewing or control here. The gateway authenticates directly using Veyon’s remote-desktop protocol. Your Veyon access-control rules still apply. Credentials and keys stay on the gateway.
